# 내 종목 뉴스 실시간 알림 봇

관심 종목(SK하이닉스, LS마린솔루션, 대한전선, 일진전기, 에이스테크, 하이트진로)에
새 기사가 뜨면 **텔레그램으로 즉시 알림**을 보내고, **웹페이지에서 지금까지 온 알림을
전부 모아볼 수 있는** 무료 자동화 시스템입니다.

- 완전 무료 (깃허브 계정만 있으면 됨, 서버/호스팅 비용 없음)
- 15분마다 자동으로 새 기사를 확인
- 신뢰할 수 있는 언론사(연합뉴스, 한국경제, 매일경제, SBS Biz 등)만 필터링해서
  블로그/커뮤니티발 찌라시는 자동으로 걸러냄
- 코딩 지식 없어도 아래 순서만 따라하면 됩니다 (15~20분 소요)

---

## 준비물
- 깃허브(GitHub) 계정 — 없으면 https://github.com/signup 에서 무료 가입
- 텔레그램 앱 (스마트폰 또는 PC)

---

## 1단계. 깃허브에 저장소 만들기

1. https://github.com/new 접속
2. Repository name에 원하는 이름 입력 (예: `stock-news-alert`)
3. **Public**으로 설정 (Public이어야 자동화가 무제한 무료입니다. 남에게 보이는 건
   "어떤 종목에 어떤 기사가 떴는지" 정도라 민감한 정보는 아닙니다)
4. `Create repository` 클릭

## 2단계. 파일 업로드

1. 방금 만든 저장소 페이지에서 `Add file` → `Upload files` 클릭
2. 이 폴더 안의 파일/폴더를 **구조 그대로** 전부 드래그해서 업로드
   (`.github` 폴더까지 반드시 포함해야 자동화가 작동합니다)
3. 화면 아래 `Commit changes` 클릭

> 만약 업로드 화면에서 `.github` 폴더가 인식이 안 되면, 압축 없이 폴더 전체를
> 통째로 브라우저 창에 드래그 앤 드롭 하면 하위 폴더까지 그대로 올라갑니다.

## 3단계. 텔레그램 봇 만들기

1. 텔레그램 앱에서 **@BotFather** 검색해서 대화 시작
2. `/newbot` 입력
3. 봇 이름 입력 (예: `내 주식 알림봇`)
4. 봇 아이디(username) 입력 — 반드시 `bot`으로 끝나야 함 (예: `my_stock_alert_bot`)
5. 완료되면 **토큰**(HTTP API 토큰, `123456:ABC-DEF...` 형태)이 나옵니다 → **복사해두기**

## 4단계. 내 채팅 ID(chat_id) 알아내기

1. 방금 만든 내 봇을 텔레그램에서 검색해서 `/start` 눌러 대화 시작 (아무 메시지나 하나 보내기)
2. 브라우저에서 아래 주소 접속 (TOKEN 자리에 3단계 토큰 붙여넣기):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. 결과(JSON) 안에서 `"chat":{"id":123456789, ...}` 형태의 숫자를 찾기 → 이게 **chat_id**

## 5단계. 깃허브에 비밀값(Secrets) 등록

1. 저장소 페이지에서 `Settings` 탭 클릭
2. 왼쪽 메뉴에서 `Secrets and variables` → `Actions` 클릭
3. `New repository secret` 클릭해서 2개 등록:
   - Name: `TELEGRAM_BOT_TOKEN` / Value: 3단계에서 복사한 토큰
   - Name: `TELEGRAM_CHAT_ID` / Value: 4단계에서 찾은 chat_id
4. 각각 `Add secret`으로 저장

## 6단계. 자동화 실행 확인

1. 저장소 상단 `Actions` 탭 클릭
2. 왼쪽에서 `Stock News Checker` 클릭
3. 오른쪽 `Run workflow` 버튼으로 지금 바로 1회 수동 실행 (테스트용)
4. 잠시 후 텔레그램으로 알림이 오는지 확인
   (처음 실행은 "읽음 처리"만 하고 알림은 보내지 않습니다 — 과거 기사 전체가
   쏟아지는 걸 막기 위한 설계입니다. **두 번째 실행부터** 새 기사에 대해 알림이 옵니다)
5. 이후로는 15분마다 자동으로 실행됩니다. 아무것도 안 해도 됩니다.

## 7단계. 웹페이지(대시보드) 켜기

1. 저장소 `Settings` → 왼쪽 메뉴 `Pages` 클릭
2. `Branch`를 `main`, 폴더는 `/ (root)`로 선택 후 `Save`
3. 1~2분 후 페이지 상단에 뜨는 주소
   (`https://내아이디.github.io/저장소이름/`)로 접속하면 대시보드 확인 가능
4. 이 페이지는 알림이 새로 쌓일 때마다 자동으로 갱신됩니다

## 종목 추가/삭제하고 싶을 때

`news_checker.py` 파일 안의 `STOCKS` 목록만 수정하면 됩니다.

```python
STOCKS = [
    {"name": "SK하이닉스", "query": "SK하이닉스"},
    {"name": "LS마린솔루션", "query": "LS마린솔루션"},
    # 여기 아래에 원하는 종목 추가
    {"name": "삼성전자", "query": "삼성전자"},
]
```

수정 후 깃허브에서 파일을 다시 저장(Commit)하면 다음 실행부터 바로 반영됩니다.

## 알림 주기를 바꾸고 싶을 때

`.github/workflows/check_news.yml` 파일의 `cron: "*/15 * * * *"` 부분에서
숫자 15를 원하는 분 단위로 바꾸면 됩니다 (너무 짧게 하면 깃허브 무료 한도를
빨리 쓸 수 있어서 5분 이상을 권장합니다).

## 신뢰 언론사 목록 조정하고 싶을 때

`news_checker.py`의 `TRUSTED_DOMAINS` 목록에 도메인을 추가/삭제하면 필터링
기준을 바꿀 수 있습니다.

---

## 문제가 생기면

- 알림이 안 온다 → `Actions` 탭에서 최근 실행 로그를 열어 에러 메시지 확인
- 웹페이지에 아무것도 안 뜬다 → 자동화가 아직 한 번도 안 돌았거나, Pages 설정이
  안 됐을 가능성. 6단계, 7단계를 다시 확인
- 텔레그램 토큰/chat_id를 잘못 넣었다 → 5단계에서 Secrets 값을 다시 수정하면 됨
